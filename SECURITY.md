# Security policy

DeepSeek-Desktop is an unofficial local process manager. It does not collect
credentials or upload Harness source code.

Please report security issues privately to the repository owner before public
disclosure. Do not include API keys, Authorization headers, session cookies,
or private source code in reports.

The application stores its own state in the platform application-data
directory. It does not modify `~/.dsh` or LM Studio configuration files.
